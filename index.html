GitHub Storage Setup

Connect a GitHub repository to persist all complaints, user accounts, and chat messages. Data is stored as JSON in data/ folder of your repo.

Not configured — using local browser storage only
Create a fine-grained token with Contents: Read and Write for your repo only.
Security note: The token is stored in your browser's localStorage, never sent anywhere except GitHub's API over HTTPS. Use a fine-grained token with minimum permissions. Do not share your token.
How it works
  1. Create a GitHub repository (can be private)
  2. Generate a fine-grained Personal Access Token with Contents: Read & Write
  3. Enter token, username and repo name above and click Test & Connect
  4. Click Initialize Data Files to create the data/ folder structure
  5. All complaints, user accounts and chat messages will now sync to GitHub
