Data Sync — Connect GitHub
Without sync, complaints submitted on your phone won't appear on your computer (and vice versa) — each device stores data in its own browser. Connecting a GitHub repository makes all data shared and visible everywhere in real time.
Not configured — using local browser storage only
Go to github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Grant Contents: Read & Write for the tamilnadu-compiliant-portal repo only.
Security note: The token is stored in your browser's localStorage, never sent anywhere except GitHub's API over HTTPS. Use a fine-grained token with minimum permissions. Do not share your token.
How it works
  1. Go to GitHub → Settings → Fine-grained tokens
  2. Create a token: select Only select repositories → tamilnadu-compiliant-portal, then grant Contents: Read & Write
  3. Paste the token above — username and repo are already pre-filled — and click Test & Connect
  4. Click Initialize Data Files to create the data/ folder structure
  5. All complaints, user accounts and chat messages will now sync to GitHub
